03 / MODEL & DATA

Designed to run locally.

Qwen2.5-0.5B-Instruct in Q4_K_M GGUF format was run on CPU with llama.cpp. The dataset is EditAttack's 100-record commonsense subset; a seeded sample of 20 records was evaluated.

04 / READ WITH CARE

A first measurement, not a final verdict.

One small model, one 20-record sample, and an exact-string proxy limit what these results can establish. No human semantic labels have been applied. Prompt formatting and dataset labels require review before final interpretation. In-context prompting does not persistently edit model weights. Results support only a descriptive comparison for this setup.
